Lode Runner (Xbox 360 XBLA, 2009) - native Windows build via ReXGlue static recompilation.

**Game files are not included.** Put your own Lode Runner XBLA package (the LIVE file, or the whole `Content\0000000000000000\5841085B\...` folder copied from your console) next to `lode_runner.exe` and run it: the first start builds the `assets` folder from it. Other versions of the game are refused with a message naming the supported one (default.xex 0.0.1.2).

- F1 / Esc: settings (display mode, window size, render resolution, VSync, aspect ratio, texture filtering, audio buffer, keyboard on/off, key rebinding). F11: fullscreen. F3: performance overlay.
- Keyboard: arrow keys move (D-pad and stick); Z = dig left (A), X = dig right (B); A / S = X / Y buttons; C / V = triggers; Q / W = bumpers; Enter = Start; Backspace = Back. All rebindable.
- Controllers work out of the box. Runs as the full game.
- Crash reports: `crash-*.txt` + `.dmp` next to the exe.

Requires 64-bit Windows 10/11 and the Microsoft Visual C++ Redistributable 2015-2022 (x64).
