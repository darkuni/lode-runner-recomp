Lode Runner (Xbox 360 XBLA) - native Windows build (ReXGlue static recompilation). Test build.

Game files are not included: put your own Lode Runner XBLA package next to `lode_runner.exe` and run it; the first start builds the `assets` folder. Needs the Microsoft Visual C++ Redistributable 2015-2022 (x64).

Settings: F1 or Esc. Crash reports: `crash-*.txt` + `.dmp` next to the exe.
